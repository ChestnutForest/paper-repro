### 1.2 列の意味

| 列 | 意味 |
| --- | --- |
| 種別 | `利用`＝人とシステムの相互作用、`機能`＝システムが自動実行する処理 |
| 分類 | `オンライン`、`非同期`、`イベント`、`手動判断`のいずれか |
| 利用者 | 初期リリースは単一の論文読解者。`system` は自動処理 |
| 状態 | `phase/status`。`*`は任意の工程、`—`は工程に依存しない |
| 要求／USDM | 確定要求ID。`REQ-C01`だけは展開済み仕様群も併記 |
| リリース | `初期`、`段階`、`将来`。要求を削除する意味ではない |

`course` は状態ではない。`reading`／`reproduction` は経路選択値として扱う。
