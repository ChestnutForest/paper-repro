REF-16 の工程成果物のうち、**外部IF項目説明**と**外部IF処理説明**を扱う。
両者は同じインタフェースについて書くため、**1インタフェース1ファイル**とし、
その中を2節に分ける（[`../arc-interface.md`](../arc-interface.md) 3.2節）。

**一覧に無いインタフェースをここへ書かない。** 一覧が目次である。

### 2.1 ⚠️ 記述しないこと

REF-16 は次を記述範囲外と定める（[`../arc-interface.md`](../arc-interface.md) 3.3節）。

| 範囲外 | 担当 |
| --- | --- |
| 取得したデータの加工ロジック | 振舞い編（[`../behaviors/`](../behaviors)） |
| 保存先のテーブル・カラム | [`../arc-datamodel-definitions.md`](../arc-datamodel-definitions.md) |

**ここには DB のカラム名を書かない。** 外部システムとやりとりする形式だけを扱う。

### 2.2 固定長ファイル前提の項目

REF-16 の構成要素には「全体レコード長」「可変長・固定長区別」がある。
これは固定長ファイルでのやりとりを想定した項目であり、**JSON でやりとりする
本プロダクトには該当しない。**

該当しない項目は `—` とし、代わりに **JSON のネスト構造を階層レベルで表す。**

## 3. 共通して従う規則

すべてのインタフェースは [`../arc-behavior-rules.md`](../arc-behavior-rules.md) の
`BR-13`（外部API呼び出し）に従う。**各ファイルへ同じ規則を書き写さない。**

| 観点 | 参照先 |
| --- | --- |
| レート制限、リトライ、タイムアウト、縮退 | `BR-13` |
| 取得値に取得元・取得日時・対象版を伴わせる | `BR-02` |
| エラーの表示 | `BR-07` |
| 著作権・ライセンスの保存 | `BR-08` |
| `unknown` を推測で埋めない | `BR-10` |
| 謝辞の表示 | [`../arc-screen-rules.md`](../arc-screen-rules.md) `CR-12` |
