## 1. 項目説明

### 1.1 送信する項目

| 階層 | 項目名 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| 1 | `arxiv_id` | 文字列 | ○ | パスに含める。**版を除いた形式**（`2404.08335`） |

⚠️ **`IF-01` と版の扱いが違う。** arXiv は版を含めるが、
Hugging Face は版なしの識別子で引く。**変換を忘れない。**

### 1.2 受信する項目

| 階層 | 項目名 | 型 | 説明 |
| --- | --- | --- | --- |
| 1 | `id` | 文字列 | arXiv識別子 |
| 1 | `title` | 文字列 | 論文題名 |
| 1 | `authors` | 配列 | 著者 |
| 1 | `publishedAt` | 日時 | 公開日時 |
| 1 | `githubRepo` | 文字列 | **公式実装のURL**。無い場合がある |
| 1 | `models` | 配列 | 紐付いたモデル。0件以上 |
| 1 | `datasets` | 配列 | 紐付いたデータセット。0件以上 |
| 1 | `spaces` | 配列 | 紐付いたデモ。0件以上 |
| 1 | `projectPage` | 文字列 | プロジェクトページ。無い場合がある |

**全体レコード長・可変長固定長区別**: `—`（JSON のため該当しない）

### 1.3 ⚠️ 本インタフェースの目的は `githubRepo` である

`models`・`datasets`・`spaces` も取得できるが、**必要なのは公式実装の紐付け**である。
リーダーボードや SOTA 追跡は要求に含まれない
（[`../../worknotes/pending-sota-comparison.md`](../../worknotes/pending-sota-comparison.md)）。

## 2. 処理説明

### 2.1 接続の条件

| 項目 | 内容 |
| --- | --- |
| 接続先 | `https://huggingface.co/api/papers/{arxiv_id}` |
| 認証 | 不要（読み取り） |
| **レート制限** | **5分固定窓**。匿名は**IPアドレス共有**、認証はユーザ単位 |
| バケット | **API バケット**（`/resolve/` を含まないため） |
| 残量の確認 | https://huggingface.co/settings/billing のゲージ |
| データ量 | 1件あたり数KB |
| 保存期間 | 制限なし |

⚠️ **他のインタフェースと窓の単位が違う。** arXiv は秒、GitHub は時、
**Hugging Face は5分**である。同じ間隔制御を流用しない。

### 2.2 事前条件

- `IF-01` で arXiv 識別子を取得済みである。
- **版を除いた識別子に変換済み**である（1.1節）。

### 2.3 本処理

1. 版なしの識別子をパスに含めて要求を送る。
2. 応答を JSON として解析する。
3. `githubRepo` があれば、`IF-02` の入力とする。
4. 取得元・取得日時を伴わせて保存する（`BR-02`）。

### 2.4 終了条件

| 結果 | 状態 | 次の動作 |
| --- | --- | --- |
| `200` かつ `githubRepo` あり | 成功 | `IF-02` へ渡す |
| `200` かつ `githubRepo` なし | **紐付けなし** | 実装が未登録。`IF-02` の検索で代替 |
| `404` | **未索引** | 論文が索引されていない |
| `429` | 一時的な失敗 | `RateLimit` ヘッダの秒数に従い再試行 |

### 2.5 ⚠️ 未索引と実装なしを区別する

**Hugging Face は全論文を索引していない。** 索引は、model card や README に
arXiv URL が書かれたときに自動で行われる。

| 応答 | 意味 | **誤った解釈** |
| --- | --- | --- |
| `404` | 論文が未索引 | ❌「実装が存在しない」 |
| `githubRepo` が無い | 実装が未登録 | ❌「実装が存在しない」 |

**いずれも `unknown` として扱う**（`BR-10`）。実装の不在を意味しない。

### 2.6 ⚠️ 429 の扱い

`RateLimit` ヘッダに**リセットまでの秒数**が入る。
`BR-13` に従い、**独自の間隔より優先する。**

⚠️ **匿名の制限は IP アドレス共有である。** 同じ回線の他の利用と枠を分け合う。
GitHub と同じ構造であり、認証すればユーザ単位になる。

### 2.7 代替手段

**`IF-02` の検索**で代替できる。ただし論文名で検索しても、
**それが公式実装とは限らない**（`IF-02` 1.1節）。紐付けの根拠が弱くなる。
