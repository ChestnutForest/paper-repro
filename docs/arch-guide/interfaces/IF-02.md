## 1. 項目説明

### 1.1 送信する項目

| 階層 | 項目名 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| 1 | `Authorization` | ヘッダ | ○ | **`Bearer <token>`**。`token` 形式は403になる |
| 1 | `owner` | 文字列 | ○ | リポジトリ所有者 |
| 1 | `repo` | 文字列 | ○ | リポジトリ名 |

⚠️ **リポジトリの特定は `IF-03` が担う。** 本インタフェースは、
特定済みのリポジトリの詳細を取得する。名前で検索して推測しない。

### 1.2 受信する項目

| 階層 | 項目名 | 型 | 説明 |
| --- | --- | --- | --- |
| 1 | `full_name` | 文字列 | `owner/repo` |
| 1 | `description` | 文字列 | 説明。`null` がありうる |
| 1 | `html_url` | 文字列 | リポジトリのURL |
| 1 | `default_branch` | 文字列 | 既定ブランチ名 |
| 1 | `license` | オブジェクト | ライセンス。**`null` がありうる** |
| 2 | `license/spdx_id` | 文字列 | `MIT`、`Apache-2.0` など |
| 1 | `pushed_at` | 日時 | 最終更新 |
| 1 | `archived` | 真偽 | アーカイブ済みか |
| 1 | `stargazers_count` | 整数 | スター数 |

**全体レコード長・可変長固定長区別**: `—`（JSON のため該当しない）

### 1.3 ⚠️ スター数を重要度の根拠にしない

`stargazers_count` は取得するが、**実装の正しさや重要度を示さない。**
`BR-08` は「引用数、人物属性だけで真偽を確定しない」と定める。同じ扱いとする。

### 1.4 ⚠️ ライセンスが `null` の場合

**ライセンス不明を「自由に使える」と解釈しない。** 明示が無ければ、
著作権法上は全権利が留保されている。

`BR-08` に従い、ライセンス情報を保存する。`null` は `unknown` として記録する。

## 2. 処理説明

### 2.1 接続の条件

| 項目 | 内容 |
| --- | --- |
| 接続先 | `https://api.github.com/repos/{owner}/{repo}` |
| 認証 | **fine-grained PAT**（公開リポジトリの読み取りのみ） |
| レート制限 | 未認証 60/時、**認証 5,000/時** |
| 二次制限 | 同時接続100、REST 900ポイント/分 |
| 残量の確認 | `X-RateLimit-Remaining` ヘッダ、`/rate_limit` |
| データ量 | 1件あたり数KB |
| 保存期間 | 制限なし。ただしライセンス情報を伴わせる |

### 2.2 事前条件

- 対象リポジトリが特定済みである（`IF-03` または利用者の指定）。
- 認証トークンが環境変数から読める。**無い場合も呼び出しは行う**（`BR-13`）。
- 残量が枯渇していない。

### 2.3 本処理

1. `Authorization: Bearer <token>` を付けて要求を送る。
2. 応答を JSON として解析し、1.2 の項目を取り出す。
3. `X-RateLimit-Remaining` を記録する。
4. 取得元・取得日時を伴わせて保存する（`BR-02`）。

### 2.4 終了条件

| 結果 | 状態 | 次の動作 |
| --- | --- | --- |
| `200` | 成功 | 探索結果として保存 |
| `404` | **該当なし** | リポジトリが存在しないか非公開 |
| `401` | **トークンの期限切れ・無効** | 再発行を促す。障害と表示しない |
| `403` + 残量0 | レート制限 | `BR-13` に従い再試行 |
| `429` | 一時的な失敗 | 同上 |

### 2.5 ⚠️ 401 を障害と表示しない

fine-grained PAT は**最長366日で失効**し、12か月未使用でも自動削除される。

`401` は「トークンの期限が切れています。再発行してください」と伝える。
「GitHub に接続できません」では、利用者は何をすべきか分からない（`BR-07`）。

### 2.6 ⚠️ 未認証時の縮退

トークンが無い場合、**60/時で動作する。** 動作は止めないが、
**制限が低い旨を画面に表示する**（`BR-13`）。

⚠️ **未認証の制限は IP アドレス単位である。** 同じ回線の他の利用と共有する。

### 2.7 代替手段

**利用者によるリポジトリURLの直接指定**で代替できる。
探索が失敗しても、利用者が知っていれば入力できる。
