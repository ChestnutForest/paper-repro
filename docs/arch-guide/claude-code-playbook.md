# Claude Code 依頼テンプレート（paper-repro）

CCAFのノウハウを反映した、Claude Code への依頼文テンプレート。
`.claude/commands/` にスラッシュコマンドとして置くと、チームで再利用できる。

## 共通の原則（CCAF Domain 3 由来）

- **まず計画を出させる**：複数ファイル・アーキテクチャ判断は、実装前に変更計画を箇条書きで出させ、合意してから実装。
- **範囲を絞る**：一度に広げず、縦切りで1本通す。
- **テストで確かめる**：実装後にテストを回し、緑になってから次へ。
- **独立レビュー**：生成コードのレビューは別セッション/別インスタンスで。

---

## テンプレA：新機能の実装依頼（プランモード向け）

```
CLAUDE.md と docs/product-design.md、docs/roadmap.md を読んでください。
いまは＜フェーズ番号・機能名＞に取り組みます。

目的：＜何を実現したいか＞

制約：
- ＜守るべき設計原則。例: 状態遷移はstates.pyのcan_transitionで検証する＞
- 既存APIの入出力（レスポンスの形）は変えないこと
- ＜構造化出力が要るなら＞ 抽出はtool_use + JSONスキーマで受け、欠損項目はnull可にすること

まず変更計画を箇条書きで出してください。
どのファイルを新規作成し、どのファイルをどう変更するかを示してから、実装に入ってください。
いきなり全部書かず、計画に合意してから進めます。
```

## テンプレB：論文情報の構造化抽出（CCAF Domain 4 由来）

```
＜対象の論文情報＞を構造化して抽出する処理を実装したい。

要件：
- 抽出はtool_use + JSONスキーマで受けること
- 論文に存在しない項目はnullを返すこと（値を捏造しないため、必須にしない）
- 判定不能なケース用に、enumに "unclear" を含めること
- 分類外は "other" + detail文字列で受けられるようにすること

多様な論文構造（インライン引用 vs 参考文献欄、ナラティブ vs 表）に対応するため、
入出力の例を2〜4個、few-shotとしてプロンプトに含めてください。
```

## テンプレC：サニティチェックの検証・リトライ（CCAF Domain 4 由来）

```
＜対象の検証＞にリトライループを実装したい。

要件：
- 検証（スキーマ/実行）が失敗したら、失敗内容を次の試行のプロンプトに含めて自己修正させること
- ただし「情報が元から存在しない」ことによる失敗は、リトライしても無駄なので区別し、
  「取得不能」として扱うこと（フォーマット不一致や構造エラーはリトライ対象）
- 失敗種別（transient/validation/permission）を構造化して返すこと
```

## テンプレD：独立レビュー（CCAF Domain 4 由来）

```
＜対象のコード＞を、生成したときの文脈を持たない独立した視点でレビューしてください。
自己レビューではなく、初見のレビュアーとして、バグ・セキュリティ・設計の問題を指摘してください。
軽微なスタイルは対象外。報告は「場所・問題・深刻度・修正案」の形式で。
```

## テンプレE：CLAUDE.md分割（CCAF Domain 3 由来）

```
肥大化したCLAUDE.mdを .claude/rules/ に分割したい。

要件：
- project-levelのCLAUDE.mdには普遍的な原則だけ残す
- backend用（paths: ["backend/**/*.py"]）とfrontend用（paths: ["frontend/**/*.tsx", "frontend/**/*.ts"]）
  で規約ファイルを分け、YAMLフロントマターのpathsでglob指定する
- 該当ファイルを編集するときだけ読み込まれるようにする

まず分割案（どのルールをどのファイルに、どのglobで）を出してから実装してください。
```

## スラッシュコマンド化の手順（任意）

上のテンプレを `.claude/commands/` に置くと、`/コマンド名` で呼べる。

1. `.claude/commands/` フォルダを作る
2. 例: `.claude/commands/implement.md` にテンプレAを入れる
3. Claude Code で `/implement` と打つと呼び出せる
4. git管理すればチーム共有できる（project-scoped）

CCAF Domain 3：project-scopedコマンドは .claude/commands/、個人用は ~/.claude/commands/。
