## 0. 本書の役割

確定要求で必要となる17エンティティの目次である。**要求33件のうち9件は未対応**（3.1節）。詳細属性は
[`arc-datamodel-definitions.md`](arc-datamodel-definitions.md)、関係は
[`arc-datamodel-er.md`](arc-datamodel-er.md)、操作は
[`arc-datamodel-crud.md`](arc-datamodel-crud.md)を正本とする。

分類はPaper-repro固有であり、実装方式を固定するものではない。

| 分類 | 意味 |
| --- | --- |
| 集約 | プロジェクト全体の識別子、経路、工程、実行状態を束ねる |
| 情報源 | 外部から取得し、版と取得条件を伴って保持する |
| 版付き成果 | 編集・生成・訂正の履歴を持つ成果物 |
| 分析記録 | 主張、証拠、条件、仮定、差分などの検討結果 |
| 実行記録 | 実行・照合・コストなどの発生事実 |
| 判断記録 | 人間の承認、理由、対象、時刻を保持する |
| 学習記録 | 理解、質問、深掘りの状態を保持する |

### 1.1 ⚠️ `DM-E18` は `Project` に紐づかない

`DM-E01`〜`DM-E17` はすべて `Project` の配下にあるが、**`DM-E18` だけは利用者に紐づき、
プロジェクトを横断して保持する。** 2本目以降の論文で既習の項目を省くために必要だからである
（[`../requirements-decisions/batch-06-options.md`](../requirements-decisions/batch-06-options.md) 選択肢3）。

⚠️ **保持するのは「読んだ／受講した」という事実に限る。**
熟達段階や理解度を保持しない。作業記録からの推定も行わない。
`REQ-C04-S02`（流暢さだけで理解済みにしない）および `REQ-C10`（LLMではなく人間が最終判断を承認できる）
との衝突を避けるためである。

⚠️ **本書以外の成果物への反映は未了である**（2026年9月2日時点）。
ER図、CRUD図、論理属性定義、および各文書の「17エンティティ」という記述は、`DM-E18` を含まない。
**次の作業単位で追随させる。** 決めるべき事項は [`../worknotes/pending-dm-e18-propagation.md`](../worknotes/pending-dm-e18-propagation.md) を参照。

⚠️ **利用者を表すエンティティは現時点で本件のみである。** 認証・アカウント管理は要求に無く、
単一利用者を前提とする。複数利用者へ拡張する場合は本書を見直す。

## 4. 主管と保存期間の未決事項

初期リリースは単一利用者であるため、組織上の主管部署は設定しない。代わりに、
「誰が値を生成し、誰が最終確定できるか」を主管欄に記した。

保存期間、最大件数、増加率は、確定要求に具体値がないため推測しない。
フェーズ1で`Paper`の平均本文サイズと版数、フェーズ3で分析・学習記録数、
フェーズ4で実行ログと成果物容量を実測し、物理設計時に根拠付きで追記する。
