# 決定記録：バッチ編・帳票編を対象外とする

- 対象プロダクト: `paper-repro`
- 文書種別: 設計判断の記録
- 決定日: 2026年9月1日
- 契機: 外部インタフェース編の完了により、残る2編の扱いを決める必要が生じたこと
- 影響先: [`../arch-guide/arc-artifact-order.md`](../arch-guide/arc-artifact-order.md) 5節、
  ルート [`../../README.md`](../../README.md) の設計工程表

---

## 1. 何を決めたか

**REF-16 のバッチ編と帳票編は、本プロダクトの対象外とする。**

設計工程の表では `⬜`（未着手）ではなく **`—`（非該当）** と表す。
空欄のまま残すと、次に見た人が「これから作るもの」と誤解するためである。

## 2. バッチ編を対象外とする根拠

REF-16 のバッチ編は、**定時・定期に自動起動される一括処理**を扱う。

### 2.1 該当する処理が存在しない

| 確認対象 | 結果 |
| --- | --- |
| [`../requirements.md`](../requirements.md)・[`../requirements-usdm.md`](../requirements-usdm.md) | 定期実行・定時起動・スケジュール実行を求める要求は無い |
| [`../arch-guide/arc-behavior-list.md`](../arch-guide/arc-behavior-list.md) の47業務 | 定期実行・自動起動・夜間処理に該当する業務は0件 |

⚠️ **「1バッチ過学習」は本編のバッチではない。** `requirements.md` 91行・343行・385行に現れる
「バッチ」は、機械学習のミニバッチ（サニティチェックの一段）を指す。
定時実行の一括処理とは無関係である。同様に「スケール」「スケジュール」も学習の進め方を指す。

### 2.2 非同期処理は別の枠組みが扱う

本プロダクトの非同期処理は、**すべて利用者の操作を起点とするジョブ**である。
論文取り込み、実装探索、spec 生成、サンドボックス実行のいずれも、利用者が画面で開始する。

これらの規則は [`../arch-guide/arc-behavior-rules.md`](../arch-guide/arc-behavior-rules.md)
`BR-12`（非同期処理とサンドボックス）が定めている。**バッチ編を追加すると責務が二重になる。**

## 3. 帳票編を対象外とする根拠

REF-16 の帳票編は、**印刷を前提とした出力**の設計を扱う。

### 3.1 印刷帳票が存在しない

本プロダクトの出力は次の2つだけである。

| 出力 | 形式 | 根拠 |
| --- | --- | --- |
| 画面表示 | ブラウザ | 画面編（[`../arch-guide/arc-screen-list.md`](../arch-guide/arc-screen-list.md)）が扱う |
| 成果物のダウンロード | 規約名 zip | `requirements.md` 346行・389行、`product-design.md` 245行 |

要求・設計のいずれにも、**印刷・帳票・レイアウト定義を求める記述が無い。**

### 3.2 「レポート」は帳票ではない

`requirements.md` 363行の「照合・レポート」はフェーズ5の名称であり、
実体は**スコア照合の画面表示と成果物のダウンロード**である。
帳票編が想定する、印刷を前提とした定型出力ではない。

## 4. 見直す条件

次のいずれかが生じたら、本決定を見直す。

| 条件 | 該当する編 |
| --- | --- |
| 定期実行される処理を要求として採用したとき | バッチ編 |
| 印刷を前提とした定型出力を要求として採用したとき | 帳票編 |
| `REQ-C11`（成果物の外部送信）の具体化で、定型フォーマットの生成が必要になったとき | 帳票編 |

⚠️ **`REQ-C11` は初期リリースの対象外である**（[`../arch-guide/arc-interface-list.md`](../arch-guide/arc-interface-list.md) 3.2節）。
具体化の際に本決定を再確認する。

## 5. これにより設計工程はどうなるか

REF-16 の6編のうち、**4編を作成し、2編を非該当として閉じた。**

| 編 | 状態 |
| --- | --- |
| 画面 | ✅ 作成済み |
| システム振舞い | ✅ 作成済み |
| データモデル | ✅ 作成済み（成熟度は仕掛。物理仕様は `Project`／`Paper` のみ確定） |
| 外部インタフェース | ✅ 作成済み |
| バッチ | — 非該当（本書） |
| 帳票 | — 非該当（本書） |

⚠️ **「6編中4編」ではなく「対象4編すべて」である。** 分母が変わる。
