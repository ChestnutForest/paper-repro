## 運用

1. 「今日の分を資産化して」で devlog を生成する
2. このフォルダ（docs/devlog/）に置く
3. `git add docs/devlog/ && git commit -m "docs: add devlog YYYY-MM-DD" && git push`
4. NotebookLM の「ソースを追加」からアップロードする
