## 語彙・用語リスト（プロジェクト固有）
このプロジェクトで出た固有用語を、毎回定義ごと書く。

| 用語 | 定義 |
|---|---|
| 仕様ID粒度 | システム化業務の対応欄が、要求ID（`REQ-C09` など）ではなく仕様ID（`REQ-C09-S01.10` など）を指している状態。どの仕様を実現する業務かが業務の側から特定できる |
| 置換不要 | 対応する要求が第2フェーズ送りで仕様が展開されておらず、仕様IDへ置き換える対象が存在しないため、要求ID粒度のまま残す業務。paper-repro では `B-01-006`・`B-06-005`・`B-06-006` の3件 |
| `DM-E18 LearningProfile` | 既読論文・既学習資料・専門分野を、プロジェクトを越えて保持する論理エンティティ。2026年9月2日に新設。ER図・CRUD図・論理属性定義には未追随で、それらの文書の「17エンティティ」という記述は `DM-E18` を含まない |
| `Provenance` | 情報の由来（どこから取得し、どの版で、どの条件で取得したか）を保持する論理エンティティ。2026年9月9日に属性が6から12へ倍増した |
