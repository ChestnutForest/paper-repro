### 検証で分かった重要な限定

- 3つの一次資料はいずれも**教育学・人類学・環境科学など、計算機科学以外の分野の学部・大学院科目**である。定量データ分析や仮説検定の扱いは、機械学習論文の再現実装とは前提が異なる。
- したがって本書は、スキル体系を**そのまま要求へ写さず**、`paper-repro` の目的（論文を読み解いて再現実装する）に照らして取捨した。
- 生成AIの回答が挙げた7領域という区分自体は、一次資料のいずれにも同じ形では存在しない。本書では区分を検証の出発点としてのみ使い、根拠は各一次資料の記述に置いた。

## 2. 検証の方法（メイン項目とサブ項目の判定基準）

| 区分 | 判定基準 |
|---|---|
| **メイン項目** | 単独で1つの機能・成果物として独立し、`paper-repro` の工程のうち1ステップを完結させる。論文を替えても同じ手順で反復される |
| **サブ項目** | 単独では成立せず、特定のメイン項目または既存要求の入力条件・出力形式・品質条件として意味を持つ |
| **既存要求の補強** | 新しい要求を立てず、既に選択済みの要求の根拠を強めるにとどまる |
| **要求として採らない** | 製品の外側にある人間の活動、または `paper-repro` の目的に対応しない記述 |

## 4. メイン項目

### AR-M-01 引用と参考文献の管理

- **根拠**: Sussex が科目の冒頭に「引用の作法（the conventions of academic referencing）」を置いていること。Kent が学習目標8.3として「文献を適切に執筆し引用できること」を明示していること。
- **要求**: 読解と再現実装の過程で参照した文献を、書誌情報つきで蓄積し、指定した引用スタイルで参考文献リストとして出力する。本文中の参照箇所と参考文献リストを対応づける。
- **受入基準の案**: 出力した参考文献リストの各項目が、実際に参照した資料へ解決できること。書誌情報が欠けている項目は、欠落を明示して出力する（推測で補わない）。
- **サブ項目**
  - `AR-S-01-1` 引用スタイル（APA など）を選択でき、同一プロジェクト内で表記を統一する。
  - `AR-S-01-2` 短縮形の引用と完全な書誌を分離して保持し、本文には短縮形だけを置く。
  - `AR-S-01-3` 参照した資料の閲覧日を記録する（ウェブ資料で必須）。
  - `AR-S-01-4` 原典と、原典を解説した二次資料を区別して記録する。
  - `AR-S-01-5` 引用箇所を、原文の転載ではなく要約として保持する。
- **重複要確認**: `REQ-C09-S02`（重要な参考文献の深掘り）および `simclr-handson-deck.md` の `PR-M-01`（書誌カード）と重なる。本書の追加分は「**出力側**の引用体裁」である。

### AR-M-02 研究倫理とアカデミック・インテグリティの担保

- **根拠**: Sussex が科目内容として研究倫理（research ethics）を明示していること。Galway が学術研究を「権威をもって述べられるようにするための過程」と定義していること。
- **要求**: 成果物に対し、出典の明示、生成AIの関与の記録、他者の著作物の扱いを点検する仕組みを持つ。点検結果を成果物に添付できる。
- **受入基準の案**: 生成AIが生成した記述と、一次資料に根拠がある記述を、成果物上で区別できること。
- **サブ項目**
  - `AR-S-02-1` 生成AIによる出力であることを記録し、成果物へ開示できる。
  - `AR-S-02-2` 引用元の権利条件（ライセンス、転載可否）を記録する。
  - `AR-S-02-3` 図表・数式・コードを複製せず、出典を示して参照させる。
  - `AR-S-02-4` 再現実装で用いたデータの取得元と利用条件を記録する。
  - `AR-S-02-5` 根拠のない記述を成果物に残さないための点検を、出力前に実行する。
- **重複要確認**: `REQ-C10-S05`（生成内容の検証と誤りの指摘）と隣接する。本書の追加分は「**検証**ではなく**開示と権利**」である。

### AR-M-03 研究プロジェクトの計画と進捗の管理

- **根拠**: Sussex が科目全体を通年で構成し、最終的な major project へ収束させる設計をとっていること。同科目が総学習時間600時間（うち接触66時間、独習534時間）と工数を明示していること。Kent も総学習時間150時間を明示していること。
- **要求**: 論文1本の読解から再現実装までを1つのプロジェクトとして扱い、工程の分解、所要時間の見積り、進捗の記録を行う。
- **受入基準の案**: 各工程に見積りと実績の両方を持ち、差が確認できること。
- **サブ項目**
  - `AR-S-03-1` 工程を「読解」「再現計画」「実装」「評価」「まとめ」に分解し、順序を保持する。
  - `AR-S-03-2` 工程ごとに見積り時間と実績時間を記録し、次回の見積りへ反映する。
  - `AR-S-03-3` 中断と再開に耐えるよう、どの工程まで進んだかを保持する。
  - `AR-S-03-4` 独習時間が大半を占める前提で、1回の作業単位を短く区切れるようにする。
- **重複要確認**: `simclr-handson-deck.md` の `PR-M-08`（計算資源制約に合わせた設定の縮約）と接続する。あちらは計算資源、こちらは**人間の時間**を扱う。

## 5. 既存要求の補強にとどまる領域

| 領域 | 一次資料の記述 | `paper-repro` での扱い |
|---|---|---|
| 文献調査・情報探索 | Kent 学習目標8.1（図書館とオンライン資源で学術調査を行う）、Galway の「探索・特定・抽出」 | 既存の `REQ-C03-S01`・`REQ-C07-S01`（論文を入手する）の根拠を補強するにとどまる |
| 批判的読解・評価 | Galway の「評価」、Kent 学習目標8.2（学術論文を分析する）、Sussex の「批判的・反省的な理解」 | 既存の `REQ-C10` 系（議論が成立する条件の確認）の根拠を補強するにとどまる |
| 研究デザイン・方法論 | Sussex の「方法論の立場」「研究方法」、Kent の定量・定性データの扱い | `simclr-handson-deck.md` の `PR-M-05`・`PR-M-06`（構成要素分解、目的関数の抽出）と重なる。分野が異なるため、そのままは写さない |
| 発表・コミュニケーション | Kent の口頭発表・ポスター発表、Sussex の「進行中の成果の発表」 | `simclr-handson-deck.md` の `PR-M-16`（定型章立ての解説アウトプット生成）と重なる。**ポスター形式**の出力だけが新規のサブ項目候補（`AR-S-04-1`） |

- `AR-S-04-1` 解説アウトプットの出力形式として、スライドとレポートに加えてポスター（1枚に収める形式）を選べる。
- `AR-S-04-2` 進行中の未完成な成果物を、完成物と区別した状態で共有できる。
- `AR-S-04-3` 検索した文献のうち、採用したものと除外したものを、判断理由つきで残す。

## 6. 要求として採らないと判断したもの

| 記述 | 判断理由 |
|---|---|
| 協働のグループワーク、相互支援（Sussex） | 人間同士の活動であり製品機能ではない。`section-1.2.3.1-small-group-discussion.md` と同じ判断 |
| 定性データの収集・分析、仮説検定のための定量データ整理（Kent） | 人類学・環境科学の学部教育を前提とする内容で、機械学習論文の再現実装には対応しない |
| キャリア上の有用性（技術発表、TOEIC、グローバル人材）に関する記述 | 生成AIの回答に含まれる助言であり、一次資料に根拠がなく、製品要求でもない |
